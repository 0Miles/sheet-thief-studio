## M0 要回答的問題

| 編號 | 問題 | 通過條件 |
|---|---|---|
| S1 | alphaTab 1.9 的授權與譜面上的標記 | 自用可以接受 |
| S2 | 100 小節 × 5 聲部時的打譜延遲 | 按鍵到畫面 p95：顯示一個聲部 ≤ 80 ms，五個聲部 ≤ 150 ms |
| S3 | TAB、鼓、五線譜、空小節的游標定位 | 都能算出游標位置 |
| S4 | 兩人同時在同一小節輸入 | 兩邊結果一致，沒有重複或遺失；各自復原互不影響 |
| S5 | 播放中修改後重新產生聲音 | 不破音，位置不跑掉 |
| S6 | 鼓件與升降記號的拼寫 | 可以由文件指定 |

S1–S4 通過才進 M1。備案：

- S1 不能接受：固定用 alphaTab 1.8.4，鼓改用標準打擊樂記譜。
- S2 不達標：只重繪游標附近的小節；再不行，編輯視圖改成自己畫，並重新評估 M1b。

## 不做的事

- 公開註冊、付費方案。
- 手機與平板上打譜（只看譜與播放）。
- 多人同步播放。
